# Overview

## Summary

`AuroraEdge Engineering KB` is a public reference vault demonstrating `wiki-context`'s three-layer architecture:
- `sources/` holds authoritative RFCs, ADRs, and quota CSV tables.
- `mirrors/` (generated via `wctx sync`) holds structured Markdown mirrors and the SQLite FTS5 index.
- `wiki/` holds cross-document compiled synthesis pages with verifiable `sources` provenance.
